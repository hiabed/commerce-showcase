# Morrow Commerce Showcase

A polished, frontend-only e-commerce template built with Next.js. The project presents a premium bag and accessories storefront designed for client demonstrations, early product exploration, or as a visual foundation for a future commerce platform.

The visual direction is inspired by the clean product browsing and promotional-product presentation of the supplied IGO Profil reference, but the brand, layout, copy, styling, and product presentation are original.

## Overview

**Morrow** is a sample lifestyle accessories brand with a calm, editorial visual identity. The showcase focuses on:

- Clear product discovery
- A premium, non-technical presentation
- Strong storytelling around materials and purpose
- Small interactions that make the prototype feel like a real store
- Responsive behavior across desktop and mobile screen sizes

This version intentionally has no backend, database, authentication, payments, or persistent cart. All product data and interactions are local to the page.

## Features

### Storefront experience

- Announcement bar with shipping information
- Branded navigation header
- Hero section with editorial headline, supporting copy, call to action, and lifestyle imagery
- Brand values section covering purposeful form, honest materials, and long-term design
- Responsive product catalog
- Product category filtering:
  - All pieces
  - New arrivals
  - Everyday
  - Travel
  - Sustainable
- Product cards with product name, category, price, editorial tag, and quick add button
- Dynamic bag counter
- Sustainability and materials feature section
- Newsletter subscription form with success state
- Footer navigation grouped into Explore, Help, and Follow

### Responsive design

The layout adapts for smaller screens by:

- Switching the navigation to a mobile menu
- Converting multi-column sections into stacked layouts
- Reducing product image sizes for mobile catalog browsing
- Keeping product filters horizontally scrollable
- Reflowing the newsletter and footer sections

## Getting started

### Requirements

- Node.js 20 or newer is recommended
- npm

### Install dependencies

From the project root:

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the URL printed in the terminal. The default URL is usually:

```text
http://localhost:3000
```

If port `3000` is already occupied, Next.js automatically uses another available port, such as `3001`.

### Create a production build

```bash
npm run build
```

### Run the production server

```bash
npm run start
```

### Run linting

```bash
npm run lint
```

## Main implementation details

### Product data

The sample products are defined near the top of `src/app/page.tsx` in a local `products` array. Each product includes:

- `name`
- `category`
- `price`
- `tag`
- `image`
- `tone`

To add or update a showcase product, edit that array and keep the same object shape.

### Category filtering

React state tracks the selected category. The visible product list is derived with `useMemo`, so selecting a category immediately updates the catalog without a page reload or backend request.

### Bag interaction

The bag counter is a lightweight demonstration interaction. Clicking either a product `+ Add` button or the header Bag button increments the local counter.

The current implementation does not store product line items or calculate totals. Those capabilities can be added when a backend or commerce provider is introduced.

### Newsletter form

The newsletter form validates that an email address is entered and then displays a local confirmation state. It does not send data to an external service yet.

## Visual system

The design uses:

- Deep green ink for brand contrast
- Warm cream backgrounds
- Muted sage accents
- Editorial serif headings
- Neutral sans-serif body copy
- Fine borders and generous spacing
- Large lifestyle imagery for product storytelling

The main colors and responsive rules are defined in `src/app/globals.css`.

## Images

The prototype uses remote Unsplash image URLs for sample product and lifestyle imagery. For a production project, replace these URLs with:

- Optimized local assets
- A CMS image service
- A CDN
- A commerce platform product media system

Using local or CDN-hosted images is recommended before presenting the project in an environment where external image requests may be blocked.

## Suggested next steps

This is a visual frontend template. To turn it into a complete e-commerce platform, the next implementation steps could include:

1. Rename the package and configure the project branding.
2. Move product data into a CMS or database.
3. Add product detail pages.
4. Implement a persistent cart and checkout flow.
5. Add customer accounts and authentication.
6. Connect the newsletter form to an email provider.
7. Replace remote demo images with optimized production assets.
8. Add analytics, SEO pages, structured product metadata, and accessibility review.
9. Add a backend API for inventory, orders, and customer data.
10. Add automated unit, integration, and end-to-end tests.
